## 最初需求（保留原文）

> 更新agent.md ，更新当前信息，增加代码提交约束，

## 背景与目标

仓库已有实际提交、AI 接入、图书及系列管理、照片录入和家庭试用部署，既有指南仍写“尚无提交”和“deployment 为占位目录”。更新贡献者入口，让 Agent 能使用当前命令和目录，并在提交前保护已有工作、完成相关验证。

## 范围与非目标

- 包含：更新既有 `AGENTS.md` 的项目现状、结构、命令、测试和领域约束；增加 Git 提交、验证、内容与历史保护约束；维护配套 spec/plan 和索引。
- 包含用户后续确认的本任务验证通过后自动本地提交。
- 不包含：修改业务代码、清理其他未提交改动、实施 Git hooks 或 CI 新规则、推送。
- 依赖：[001 文档维护约定](../001-spec-plan-workflow/spec.md)、当前工作区、项目 README、前端脚本、CI 和部署说明。沿用既有 `AGENTS.md`，不创建重复 `agent.md`。
