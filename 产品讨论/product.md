# 儿童英语阅读辅助产品：第一版范围

> 讨论记录，更新于 2026-09-23。本文记录已明确的产品方向与仍需设计的问题，不指定技术栈。

## 一句话项目目标

帮助 1.5～7 岁孩子的家长，根据孩子的实际表现，从家中已有英语读物中选择适合当天的内容，逐步建立可持续的共读习惯，并通过反馈持续改进建议。

## 目标用户与问题

- **第一位用户**：家长本人；第一版只管理一个孩子。
- **孩子年龄**：1.5～7 岁。年龄用于适龄内容和提问方式的约束，不能单独决定阅读能力或学习阶段。
- **核心问题**：家长难以判断孩子当前适合什么内容，也难以每天决定读什么、观察学习状态并据此调整安排。产品需要降低这部分决策负担，同时避免让孩子因内容或互动方式不合适而抵触学习。
- **当前解决方式（待验证的假设）**：家长在已有图书、分级参考资料和日常观察之间自行判断，靠记忆或零散记录调整后续阅读。尚无用户访谈证据证明这一过程的频率和具体困难。

## 产品原则

1. **评估实际表现**：通过家长报告的具体行为和后续共读反馈判断状态，不按年龄直接分级，也不要求低龄孩子接受测验。
2. **习惯与接受度优先**：目标是孩子愿意持续接触合适内容，并逐步进步；不要求学会或完成某一本书。重复阅读可以有价值。
3. **建议应有依据**：展示推荐依据、证据不足的地方和调整原因。家长可以纠正判断，也可以坚持阅读自己选择的书。
4. **反馈应轻量**：先问少量易回答的问题，允许家长补充文字。助手可以将文字整理成结构化观察；当信息不清楚或会明显影响后续建议时，再向家长追问或请其确认。
5. **不将缺席误判为退步**：没读、时间冲突或一次没有回应，不直接构成能力下降的证据。

## 核心用户故事

> 作为家长，我希望通过回答孩子近期真实表现的问题，获得有依据的阅读建议。共读后，我可以用简短反馈告诉助手孩子的反应，让下一次建议更贴合孩子；如果我想读其他书，也能自行决定。

### 一次完整的核心流程

1. 家长确认家中有哪些可用的英语读物，以及已读、在读和暂停使用的资源。
2. 家长回答孩子的英语接触情况、共读习惯、可观察行为、兴趣及家庭时间安排。
3. 产品给出初步的学习状态画像，说明判断依据、尚缺的证据及建议起点；家长可以纠正。
4. 产品生成短周期阅读建议。家长查看今天的读物、互动方式、建议时长和推荐理由，并可替换或锁定内容。
5. 家长与孩子共读；孩子不愿继续时可以提前结束。
6. 家长反馈是否进行、孩子的参与情况及可选文字说明。助手整理观察，必要时请家长补充或确认。
7. 产品更新学习状态与尚未执行的建议，展示发生变化的依据。家长下次打开时清楚知道可以读什么。

## MVP 功能列表

### 1. 家庭书架

- 从现有图书清单初始化候选资源，让家长确认实际拥有和可使用的书。
- 图书和书架均以单本登记；按具体套装、级别或版本维护系列分组，套装或级别不能代替具体分册。搜索具体分册可单独加入，系列可展开查看并整组加入；已有阅读状态保留，缺少分册设为未读。
- 书架按系列默认折叠，展开后逐本管理；共享分册在各套装展示并标注“同一本书，阅读状态共享”，计数按唯一单本。语言筛选只用于查找，整组加入包含本组全部已录入分册，未来分册由家长主动补齐。
- 已加入书架的单本至少能标记未读、近期在读、熟悉及暂停使用。
- 初期推荐优先使用已确认可用的家庭资源。

### 2. 初始评估与状态画像

- 以家长观察为输入，覆盖共读频率、舒适时长、参与和抵触、理解与回应、早期识读表现、兴趣及家庭约束。
- 根据孩子的实际表现选择适用的问题；允许“不确定”或“没观察过”。
- 输出多维状态及其依据，不给孩子贴单一的能力等级、同龄排名或发育标签。
- 家长能确认或纠正初始判断。首次判断在后续实际共读中校准。

### 3. 有解释的选书建议

- 结合状态画像、兴趣、家庭书架、内容特点和已确认的分级信息提出建议。
- 对每项建议说明适合的理由，以及难度或资料方面的不确定性。
- 家长可以选择未被推荐的读物。若与当前评估有明显冲突，产品给出具体依据和低压力的阅读建议，但保留家长决定权。
- 蓝思值可以作为参考信息；缺失时不得编造，也不能只凭年龄或跨体系对照图判断单本适读性。

### 4. 短周期阅读安排

- 展示今天可读的内容、建议互动方式、参考时长和可选替换内容。
- 允许熟悉内容、新内容与观察型活动搭配；建议时长不是必须完成的指标。
- 根据完成情况及家长反馈调整尚未执行的安排，并解释原因；已完成记录保留。
- 具体的重复阅读与复习调度规则仍需后续设计，不以“掌握单本绘本”为目标。

### 5. 轻量反馈与进展回顾

- 共读后快速记录是否进行、持续时间、参与情况及可选的具体行为或文字说明。
- 助手保留反馈原文，并将其解析为可供家长确认的结构化观察；重要或不确定的解释需要追问或确认。
- 家长能查看近期阅读规律、孩子的兴趣与参与变化、当前状态及其依据，以及下一步建议。

## 非目标

第一版不包含社区分享、评论、积分、权益兑换、AI 绘本解读、自动生成分享笔记、复杂统计报表、首页拖拽配置、多孩子管理、全品类绘本库、自动识别上传绘本，以及跨分级体系的精确换算。也不要求孩子参加考试、达到某本书的掌握标准或严格执行固定复习周期。

2026-09-29 范围更新：上段为早期范围记录；其中“自动识别上传绘本”由 [004 系统图书管理与拍照录入](../specs/004-catalog-management-ai/spec.md) 更新。用户已确认管理员在前台新增/归档共享图书，混合上传照片后自动识别同一本的多张照片并分组，统一核对确认入库，可选联网补全并查看来源；每张照片主要拍一本，不做单张多本识别。默认省钱 Batch，可切换实时。本期接通验证文字、图片、音频理解能力，家长 Agent 交互界面后续做；本功能尚未实施，也不包含 AI 绘本内容解读。

## 第一版验收标准

1. 家长能确认家庭书架，完成初始评估，并看懂状态判断的依据及不确定之处。
2. 家长打开产品时，能看到当天可执行的建议，知道推荐理由，并能选择替代读物。
3. 家长能在共读后快速反馈；自由文字中的重要判断可被确认或纠正，原始反馈不会丢失。
4. 连续记录后，家长能看到反馈如何改变后续建议；未执行任务不会被当作孩子能力下降，也不会无限累积为欠账。
5. 家长能回顾共读是否逐渐稳定、孩子是否愿意参与、哪些表现有了变化，以及目前仍需观察什么。
6. 用真实使用过程验证：家长无需另用表格或日历，就能回答“今天读什么、为什么读、读后发现了什么、下次怎么安排”。

“良好习惯”“不排斥”“明显进步”和“家长不再头疼选书”是产品结果目标；观察周期与量化指标尚待设计，不能在此假定已达成。

## 待确认问题

1. 评估各维度的具体问题、不同表现的判断方式，以及何种证据足以改变阶段或阅读难度。
2. 1.5～7 岁范围内，不同发展阶段应如何选择共读互动方式；现有评估和首周计划设计稿标注的 1.5～6 岁范围需要扩展核对。
3. 面对家长指定但当前不推荐的书，产品需要展示哪些证据、提醒到什么程度、后续如何利用实际反馈重新判断。
4. 重复阅读、跳过一天、明显抵触、持续高参与等情况如何改变计划；哪些调整可直接应用，哪些要由家长确认。
5. 哪些进步信号值得追踪，如何衡量习惯、接受度、能力变化和家长的选书负担；试用观察多久。
6. 家中已有但清单信息不全的单本如何补录，以及尚待拆分的套装和级别何时完成逐本核对。
